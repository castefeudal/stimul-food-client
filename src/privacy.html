Правовая информация

Обработка данных

Форма собирает только данные, необходимые для ответа на заявку: имя, контакт, выбранный формат, адрес/район и комментарий.

Назначение

Данные используются для связи по заявке, уточнения условий пилота и не должны применяться для иных целей без отдельного основания.

Хранение

В production-режиме заявки могут сохраняться в подключённом серверном хранилище. В демонстрационном режиме форма прямо сообщает, что данные сохраняются только в браузере пользователя.

Чувствительные данные

Не указывайте медицинские документы или избыточные сведения о здоровье. Если необходимо сообщить об аллергене для обсуждения возможности заказа, ограничьтесь информацией, необходимой для этого обсуждения.

Контакты

Перед коммерческим запуском здесь должны быть указаны юридически значимые реквизиты оператора данных и способ отзыва согласия.
